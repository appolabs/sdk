## Cos'è Appo?

Appo trasforma la web app che già hai in un'app nativa iOS e Android
e ne opera la pubblicazione: build, invio agli store, revisione Apple,
aggiornamenti. Approvi tu; esegue Appo.

### Come funziona

1. **Hai una web app funzionante** — qualsiasi stack: React, Vue, HTML semplice,
   Shopify, quello che già serve i tuoi utenti.
2. **Appo crea l'app nativa dal suo URL** — non si riscrive nulla; il tuo
   sito è l'app.
3. **La vedi in anteprima sul tuo telefono** — un'anteprima installabile, gratuita.
4. **Appo pubblica e mantiene la pubblicazione** — account store, revisione,
   certificati e aggiornamenti fanno parte del percorso di pubblicazione operata.

Segui l'intero percorso in [Dagli URL agli store](/getting-started/journey),
oppure vai direttamente alle [guide](/guides/create-app).

### Scegli la tua superficie

Tutto quanto sopra funziona dalla superficie che preferisci:
[dashboard, CLI o server MCP](/getting-started/which-tool), con gli
stessi risultati su tutte e tre.

### Lungo il percorso

Quando vuoi funzionalità native nel tuo codice (notifiche push,
Face ID, fotocamera, GPS) incontrerai
[Appo SDK](/sdk): un bridge JavaScript per il codice web che già scrivi.
È parte della tua app, non un passo da cui partire.
