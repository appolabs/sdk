## Cos'è Appo?

Appo trasforma una web app esistente in un'app nativa iOS e Android e ne
opera il processo di pubblicazione: build, invio agli store, revisione
Apple e aggiornamenti. Ogni passo di pubblicazione è approvato dal
proprietario dell'app ed eseguito da Appo.

### Come funziona

1. **Si parte da una web app funzionante.** Qualsiasi stack che oggi serve
   un sito: React, Vue, HTML semplice, Shopify.
2. **Appo crea l'app nativa dal suo URL.** Il sito viene caricato in un
   wrapper nativo; non si riscrive nulla.
3. **Anteprima su dispositivo.** È disponibile un'anteprima installabile,
   senza costi.
4. **Appo pubblica e mantiene la presenza sugli store.** Account store,
   revisione, certificati e aggiornamenti fanno parte del percorso di
   pubblicazione operata.

Il percorso completo è descritto in
[Dagli URL agli store](/getting-started/journey); le
[guide](/guides/create-app) coprono le singole operazioni.

### Dashboard, CLI e server MCP

Ogni operazione è disponibile da tre superfici equivalenti:
[dashboard, CLI e server MCP](/getting-started/which-tool). Tutte e tre
producono gli stessi risultati.

### Appo SDK

Le funzionalità native (notifiche push, Face ID, fotocamera, GPS) sono
accessibili dal codice web dell'app tramite [Appo SDK](/sdk), un bridge
JavaScript. L'SDK è opzionale e si aggiunge al codice web esistente; non
è un punto di partenza obbligato.
