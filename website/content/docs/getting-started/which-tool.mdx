---
title: Dashboard, CLI or MCP?
description: "Same outcomes, three ways to drive them: pick the surface that fits your workflow."
---

Appo operates your app's publication. You drive that lifecycle from
whichever surface fits how you work — the outcomes are the same on all
three, and nothing locks you to the one you started on.

| | Dashboard | CLI | MCP |
| --- | --- | --- | --- |
| What it is | The web interface | [`appo`](/cli) in your terminal | Your AI assistant, via [`@appolabs/appo-mcp`](/mcp) |
| Fits when | You prefer a GUI | You live in the terminal or CI | You work with an agent |
| Start | [apps.goappo.io](https://apps.goappo.io) | `npm install -g @appolabs/appo` | `claude mcp add appo -- npx -y @appolabs/appo-mcp` |

They share the same account, the same apps and the same operated path:
create from the CLI, publish from the dashboard, send a push from your
assistant — mix freely.

Along the way you will also meet the [SDK](/sdk): the JavaScript bridge that
gives your web code native APIs inside the app. It is not a surface you
choose — you reach for it when you want native features.
