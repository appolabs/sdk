title: Dashboard, CLI o MCP?
description: "Stessi esiti, tre modi di guidarli: scegli la superficie adatta al tuo flusso."
---

Appo opera la pubblicazione della tua app. Guidi quel ciclo di vita dalla
superficie che si adatta al tuo modo di lavorare: gli esiti sono gli stessi
su tutte e tre, e nulla ti vincola a quella da cui hai iniziato.

| | Dashboard | CLI | MCP |
| --- | --- | --- | --- |
| Cos'è | L'interfaccia web | [`appo`](/cli) nel tuo terminale | Il tuo assistente AI, via [`@appolabs/appo-mcp`](/mcp) |
| Indicata quando | Preferisci una GUI | Vivi nel terminale o in CI | Lavori con un agente |
| Inizia | [apps.goappo.io](https://apps.goappo.io) | `npm install -g @appolabs/appo` | `claude mcp add appo -- npx -y @appolabs/appo-mcp` |

Condividono lo stesso account, le stesse app e lo stesso percorso operato:
crea dalla CLI, pubblica dalla dashboard, invia una push dal tuo
assistente. Mischia liberamente.

Strada facendo incontrerai anche l'[SDK](/sdk): il bridge JavaScript che dà al tuo codice
web API native dentro l'app. Non è una superficie da scegliere: lo usi
quando vuoi funzionalità native.
