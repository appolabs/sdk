## What is Appo?

Appo turns an existing web app into a native iOS and Android app and
operates the publication process: builds, store submission, Apple review,
and updates. Each publication step is approved by the app owner and
executed by Appo.

### How it works

1. **Start from a working web app.** Any stack that serves a site today:
   React, Vue, plain HTML, Shopify.
2. **Appo creates the native app from its URL.** The site is loaded in a
   native wrapper; nothing is rewritten.
3. **Preview on a device.** An installable preview is available at no cost.
4. **Appo publishes and maintains the listing.** Store accounts, review,
   certificates, and updates are part of the operated publication path.

The complete path is described in
[From URL to the stores](/getting-started/journey); the
[guides](/guides/create-app) cover individual tasks.

### Dashboard, CLI, and MCP server

Every operation is available from three equivalent surfaces: the
[dashboard, the CLI, and the MCP server](/getting-started/which-tool).
All three produce the same outcomes.

### The Appo SDK

Native features (push notifications, Face ID, camera, GPS) are available
to the app's own web code through the [Appo SDK](/sdk), a JavaScript
bridge. The SDK is optional and is added to existing web code; it is not
a required starting point.
