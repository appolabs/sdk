## What is Appo?

Appo turns the website you already have into a native iOS and Android app,
and operates the publication: builds, store submission, Apple review,
updates. You approve; Appo executes.

### How it works

1. **You have a working web app** — any stack: React, Vue, plain HTML,
   Shopify, whatever serves your users today.
2. **Appo creates the native app from its URL** — nothing is rebuilt; your
   site is the app.
3. **You preview it on your phone** — an installable preview, free.
4. **Appo publishes and keeps it published** — store accounts, review,
   certificates and updates are part of the operated path.

Follow the whole path in [From URL to the stores](/getting-started/journey),
or jump straight to the [guides](/guides/create-app).

### Drive it your way

Everything above works from the surface you prefer: the
[dashboard, the CLI or the MCP server](/getting-started/which-tool) — same
outcomes on all three.

### Along the way

When you want native features in your own code — push notifications,
Face ID, camera, GPS — you will meet the
[Appo SDK](/sdk): a JavaScript bridge for the web code you already write.
It is part of your app, not a step you start from.
