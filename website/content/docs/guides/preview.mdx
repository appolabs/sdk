---
title: Preview on device
description: Get an installable preview of your app on your phone at no extra cost, within 48 hours from the dashboard, minutes from the CLI or MCP.
---

Preview makes your app installable on a real device: TestFlight for iOS
and a deep link for Android. Both platforms are free. Dashboard-created apps
are available within 48 hours; created from the CLI or MCP, the preview is
ready in minutes.

<Tabs items={['Dashboard', 'CLI', 'MCP']}>
<Tab value="Dashboard">

1. Open your app on [apps.goappo.io](https://apps.goappo.io).
2. Use the open-on-device or preview action. A QR code is shown for both
   platforms.

</Tab>
<Tab value="CLI">

```bash
appo run [id]
```

Triggers a TestFlight build if none is ready, then returns the TestFlight URL
(iOS), the deep link (Android) and a QR code. If `id` is omitted, the command
uses your only app, or shows a picker when the account has several.

</Tab>
<Tab value="MCP">

Ask your assistant to preview the app: it calls `preview_app`, which returns
the iOS TestFlight URL, Android deep link, QR target, and per-platform
readiness flags.

</Tab>
</Tabs>

iOS preview readiness can lag Android: it requires a TestFlight build, which
adds processing time on Apple's side. Android preview is available as soon as
the app record exists.
