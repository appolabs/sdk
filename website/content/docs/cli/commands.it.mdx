Output di `appo --help`, raggruppato per area. Le opzioni globali funzionano
su ogni comando: `--api <url>` sovrascrive la base API (env `APPO_API_BASE`),
`--env <name>` seleziona il profilo di ambiente (env `APPO_ENV`), e
`--json` stampa il corpo grezzo della risposta API.

## Auth

| Comando | Cosa fa |
| --- | --- |
| `appo login [--api <url>]` | Autenticazione via browser (flusso device) |
| `appo login --token <pat>` | Autenticazione non interattiva con un PAT della dashboard |
| `appo logout` | Revoca il token lato server e lo rimuove localmente |
| `appo whoami` | Mostra l'ambiente attivo, l'API e lo stato di raggiungibilità |
| `appo env list` | Elenca gli ambienti configurati |
| `appo env use <name>` | Cambia l'ambiente attivo |

## Setup

| Comando | Cosa fa |
| --- | --- |
| `appo init [--token <pat>]` | Inizializza la configurazione e il primo accesso |
| `appo upgrade` | Aggiorna all'ultima versione di @appolabs/appo via npm |
| `appo --version, -v` | Stampa la versione della CLI e di Node |

## App

| Comando | Cosa fa |
| --- | --- |
| `appo apps create --name <n> --url <u>` | Crea una nuova app |
| `appo apps list` | Elenca le tue app |
| `appo apps show <id>` | Mostra un'app |
| `appo apps update <id> [--name <n>] [--url <u>] [--icon <https-url>] [--permission <name>=<on\|off>]` | Aggiorna nome, URL, icona e permessi |
| `appo apps update <id> [--prepare on\|off]` | Affida al team Appo l'adattamento del sito all'app, oppure lo riprende |

## Ciclo di vita

| Comando | Cosa fa |
| --- | --- |
| `appo new --url <u> [--name <n>] [--prepare]` | Crea un'app (il nome deriva dall'URL; con `--prepare` il team Appo adatta il sito) |
| `appo ship <id> [--stores <list>] [--yes]` | Pubblica l'app sugli store (anche ripubblicazione, o nuovo invio dopo un rifiuto) |
| `appo status <id>` | Panoramica app: stato di pubblicazione e azione successiva |
| `appo run [id]` | Prova l'app: stampa il link di anteprima e il QR code per il telefono, oppure lo stato dei lavori di Appo; non avvia alcuna build. Senza id: la tua unica app, oppure un selettore |
| `appo rejection <id>` | Mostra il rifiuto attivo dall'App Store |
| `appo fix-recipe <id>` | Mostra la soluzione suggerita per un rifiuto |
| `appo publish <id> [--confirm]` | Pubblica un'app già compilata sui suoi store |
| `appo push <id> --title <t> --body <b> [--target-url <u>] [--image-path <p>] [--scheduled-at <when>] --confirm` | Invia una notifica push |

## Build di test e dispositivi

| Comando | Cosa fa |
| --- | --- |
| `appo download <id> [--build <n>] [--output <path>]` | Scarica l'artefatto installabile quando è pronto (le build partono da sole quando l'app è pronta) |
| `appo devices list` | Elenca i tuoi dispositivi iOS di test registrati |
| `appo devices register` | Link e QR per la registrazione del dispositivo iOS (una volta per dispositivo) |
