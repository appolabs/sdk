Output of `appo --help`, grouped by area. Global options work on every
command: `--api <url>` overrides the API base (env `APPO_API_BASE`),
`--env <name>` selects the environment profile (env `APPO_ENV`), and
`--json` prints the raw API response body.

## Auth

| Command | What it does |
| --- | --- |
| `appo login [--api <url>]` | Authenticate via the browser (device flow) |
| `appo login --token <pat>` | Authenticate non-interactively with a dashboard PAT |
| `appo logout` | Revoke the token server-side and clear it locally |
| `appo whoami` | Show the active environment, API and liveness |
| `appo env list` | List configured environments |
| `appo env use <name>` | Switch the active environment |

## Setup

| Command | What it does |
| --- | --- |
| `appo init [--token <pat>]` | Bootstrap config and first login |
| `appo upgrade` | Update to the latest @appolabs/appo via npm |
| `appo --version, -v` | Print the CLI and Node version |

## Apps

| Command | What it does |
| --- | --- |
| `appo apps create --name <n> --url <u>` | Create a new app |
| `appo apps list` | List your apps |
| `appo apps show <id>` | Show one app |
| `appo apps update <id> [--name <n>] [--url <u>] [--icon <https-url>] [--permission <name>=<on\|off>]` | Update name, URL, icon and permissions |
| `appo apps update <id> [--prepare on\|off]` | Have Appo's team adapt the site to the app, or take that back |

## Lifecycle

| Command | What it does |
| --- | --- |
| `appo new --url <u> [--name <n>] [--prepare]` | Create an app (the name defaults from the URL; `--prepare` has Appo's team adapt the site) |
| `appo ship <id> [--stores <list>] [--yes]` | Ship the app to the stores (also republish, or resubmit after a rejection) |
| `appo status <id>` | App overview: publication state and next action |
| `appo run [id]` | Try it: print the preview link and QR code for your phone, or what Appo is still doing; starts no build. No id: your only app, or a picker |
| `appo rejection <id>` | Show the active App Store rejection |
| `appo fix-recipe <id>` | Show the fix recipe for a rejection |
| `appo publish <id> [--confirm]` | Publish an already-built app to its stores |
| `appo push <id> --title <t> --body <b> [--target-url <u>] [--image-path <p>] [--scheduled-at <when>] --confirm` | Send a push notification |

## Test builds and devices

| Command | What it does |
| --- | --- |
| `appo download <id> [--build <n>] [--output <path>]` | Download the installable artifact once ready (builds start automatically once the app is ready) |
| `appo devices list` | List your registered iOS test devices |
| `appo devices register` | iOS device registration link and QR (once per device) |

## AI editor

| Command | What it does |
| --- | --- |
| `appo mcp` | Connect your AI agent to Appo (Claude Code, Codex, Cursor): registers the Appo [MCP connector](/mcp) |
