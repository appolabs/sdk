La CLI Appo (`@appolabs/appo`) crea e gestisce app Appo native dal terminale
o da una pipeline CI, alla pari con la dashboard. È un client Node leggero e senza dipendenze, costruito sull'API pubblica di Appo.

Per il bridge JavaScript all'interno della tua app, vedi l'[SDK](/sdk/installation). Per guidare gli stessi risultati da un
assistente AI, vedi il [server MCP](/mcp).

## Installazione

```bash
npm install -g @appolabs/appo
```

Richiede Node 18 o successivo. Dopo l'installazione il comando `appo` è
disponibile nel PATH:

```bash
appo --version
```

## Prima esecuzione

`appo init` inizializza la configurazione ed esegue il primo accesso:

```bash
appo init
```

L'autenticazione usa il flusso device via browser: la CLI stampa un link e un
codice, li approvi nella dashboard e il token viene salvato nel profilo locale
(`~/.appo/config.json`). Per ambienti CI o non interattivi, passa un token di
accesso personale:

```bash
appo login --token <pat>
```

Nei contesti non interattivi puoi anche impostare la variabile d'ambiente `APPO_TOKEN`; ha la precedenza sul token del profilo salvato.

`appo whoami` mostra l'ambiente attivo e l'API in qualsiasi momento.
