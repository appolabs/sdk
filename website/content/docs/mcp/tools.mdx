The connector at `https://apps.goappo.io/mcp` exposes 15 tools. `get_app_overview`
is the starting read: it reports the state of the app and the single next
action. There is no separate tool for listing apps.

| Tool | Outcome | Gate |
| --- | --- | --- |
| `get_app_overview` | Reads the app's configuration, its publication state and the next action | — |
| `create_app` | Creates an app from the address of its website | — |
| `configure_app` | Updates the app's name, website address and who adapts the website to the app | — |
| `preview_app` | Tells whether the app can be tried on a phone now and returns the single preview link | — |
| `set_icon` | Sets the app icon from an image address | — |
| `set_permissions` | Sets the app's native permissions (tracking, camera, microphone, NFC) | — |
| `customize_appearance` | Applies CSS and JavaScript adjustments to how the website looks inside the app | confirm |
| `suggest_customizations` | Inspects the website and proposes adjustments for `customize_appearance`; changes nothing | — |
| `request_testflight_build` | Requests a TestFlight build so the app can be tried on a real device before publishing | confirm |
| `publish_app` | Starts publication to the selected stores | confirm |
| `get_rejection` | Returns the publication status and the required action for a rejected app, without raw reviewer text | — |
| `get_fix_recipe` | Describes the steps that resolve the current rejection | — |
| `trigger_resubmission` | Submits the app again for store review after a rejection; requires a customer-owned Apple credential | confirm |
| `send_push` | Sends a push notification to the app's users | confirm |
| `remove_app` | Removes an app that is not published | confirm |

## Confirm gate

The tools marked `confirm` accept a `confirm` argument. Without `confirm: true`
they make no change and answer with a description of what would happen; the
action is carried out when the call is repeated with `confirm: true`.
